# Gece Yarısı Buzdolabı Yargıcı

## Resmi Tanım

Bu uygulama, gece yarısı (veya herhangi bir saatte) buzdolabını açma eylemini gerçekleştirdiğinizde sizi yargılayan, aşırı ciddi, bilimsel görünen ama aslında tamamen absürt bir Python programıdır. 

Program, kullanıcının açlık krizini, vicdan azabını ve gece yarısı kararlarını analiz ederek (asla etmez) yargı kararı üretir. Çıktılar rastgele, abartılı ve gereksiz ölçüde dramatiktir.

### Özellikler
- Gerçekten çalışır.
- Hiçbir şey yapmaz ama yapıyormuş gibi yapar.
- Gece yarısı açlığınızı yargılar.
- Sonsuz döngü riski taşır (kasten).
- Buzdolabınızla konuşmaz ama konuşuyormuş gibi hissettirir.

### Kurulum ve Çalıştırma
```bash
python yargic.py
```

Sorulara cevap verin, yargı kararını bekleyin. İtiraz etmeyin, kabul edilmez.

### Yasal Uyarı
Bu program hiçbir gerçek yargı organı tarafından onaylanmamıştır. Buzdolabınızın suçluluğu kanıtlanmamıştır. Tüm hakları saklıdır (saklanmaz).
